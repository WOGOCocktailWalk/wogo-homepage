How it works
  1. Give the mail a name and click Save to Brevo. Saving never sends anything.
  2. Changed something? Save again with the same name and Brevo gets the new version.
  3. In Brevo, open Templates, find your mail and use Preview & Test to send a test to yourself and to Maroussia.
  4. Nothing goes to the subscriber list without Maroussia's OK.
