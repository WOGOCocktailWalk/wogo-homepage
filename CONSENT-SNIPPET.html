What the wiring agent must do (integration steps)

  1. Paste the block between the two WOGO COOKIE CONSENT v1 fences into every page, immediately before </body> — after the shared footer, and it does not matter whether it sits before or after each page's own foot <script>. No path/BASE changes needed: it uses no images or internal links.
  2. Wire the footer link. In the SHARED FOOTER v4, the legal links are stubbed in a comment. When they ship, make the Cookie link reopen settings: <a href="#" onclick="wogoOpenConsent();return false" data-i18n="foot_cookie">Cookie settings</a>. The NL key foot_cookie already exists in every page's dictionary.
  3. Move trackers behind the gate. Delete any hard-coded Meta Pixel / GA from the pages and re-add them using the gating pattern shown below. Cloudflare Web Analytics is cookieless and needs no consent, so it loads always.
  4. Nothing else fires before consent. Verify: with a fresh browser (no stored choice), the Network tab shows NO facebook.com / pixel requests until the visitor clicks Accept all or enables Marketing.

The gating pattern (paste your real trackers here)

Put this in each page's foot script, or its own small script. wogoOnConsent runs the callback once immediately with the current choice, then again every time the visitor changes it.

<script>
  // 1) Cloudflare Web Analytics — cookieless, no consent needed. Load it always.
  //    (swap TOKEN for your real Cloudflare beacon token)
  (function () {
    var s = document.createElement('script');
    s.defer = true;
    s.src = 'https://static.cloudflareinsights.com/beacon.min.js';
    s.setAttribute('data-cf-beacon', '{"token":"YOUR_CF_TOKEN"}');
    document.head.appendChild(s);
  })();

  // 2) Meta Pixel — MARKETING. Only ever loads when the visitor allowed marketing.
  var wogoPixelLoaded = false;
  window.wogoOnConsent(function (consent) {
    if (!consent.marketing || wogoPixelLoaded) return;
    wogoPixelLoaded = true;
    !function(f,b,e,v,n,t,s){if(f.fbq)return;n=f.fbq=function(){n.callMethod?
    n.callMethod.apply(n,arguments):n.queue.push(arguments)};if(!f._fbq)f._fbq=n;
    n.push=n;n.loaded=!0;n.version='2.0';n.queue=[];t=b.createElement(e);t.async=!0;
    t.src=v;s=b.getElementsByTagName(e)[0];s.parentNode.insertBefore(t,s)}(window,
    document,'script','https://connect.facebook.net/en_US/fbevents.js');
    fbq('init', 'YOUR_PIXEL_ID');
    fbq('track', 'PageView');
  });

  // 3) Example FUNCTIONAL / ANALYTICS gate (only if you add such tools later):
  //    window.wogoOnConsent(function (c) { if (c.analytics) { /* load GA etc. */ } });
</script>

What the snippet exposes (API)

  • window.wogoConsent — live object {analytics, functional, marketing} (booleans). Necessary is implied-always.
  • window.wogoOnConsent(fn) — runs fn(consent) now and on every change. Use this to load trackers.
  • window.wogoOpenConsent() — reopens the preferences modal (for the footer "Cookie settings" link).
  • Event wogoconsentchange on window — fired on every save (event.detail = the consent object).
  • Stored under localStorage["wogoConsent.v1"] as {v,analytics,functional,marketing,ts,lang} — ts is the ISO timestamp (proof of consent).
